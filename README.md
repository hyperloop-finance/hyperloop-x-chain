# Hyperloop X Chain

A planned Ethereum Layer 2 built with Arbitrum technology for Hyperloop's credit and derivatives ecosystem.

## Overview

Hyperloop X Chain aims to provide a dedicated, EVM-compatible execution environment for non-liquidative lending, option liquidity and collateral settlement.

The architectural reference is Robinhood Chain's relationship with Arbitrum: an independent Ethereum L2 built using Arbitrum's technology stack. Hyperloop X Chain is intended to follow this model, with Ethereum as its settlement layer. Detailed chain configuration will be determined during technical design.

## Planned scope

- Build a dedicated L2 using Arbitrum's chain infrastructure.
- Support Hyperloop Awakening's lending markets and loan lifecycle.
- Integrate Hyperloop Option Market for internal option liquidity and protection settlement.
- Provide EVM-compatible infrastructure for developers, wallets and institutional integrations.
- Define bridging, data availability, sequencing, validation and governance before testnet deployment.

## Status

Early-stage planning. This repository currently contains the project overview; no chain implementation or network deployment is included yet.
